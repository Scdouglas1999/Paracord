# IX-17 checkpoint: Long tail

Contract: `docs/index-spec.md` §6.7 (settings), §6.8 (notices), §6.10 (media viewer), §6.11 (pickers, tooltips),
§6.12 (dialogs), §6.14 (entry pages), §5.15 to §5.18 (hover, copy feedback, sheets, toasts), §8.1 (Admin and
Developer as pages), §10 (Reduced transparency, High contrast). Plan row: `docs/design/index-plan.md` §3 (IX-17).
Worktree `~/Documents/Paracord-index`, branch `feat/index-ui`.

The long tail is everything the packages that rebuild the shell do not own. After this package no screen is
Glass: the shared primitives, settings, dialogs, toasts, menus, pickers, the media viewer, the entry pages and the
Admin and Developer pages draw the Index tokens, with the one cream action, the one danger ink, flat tonal fills
and a hairline.

Three workers built the areas in parallel from one foundation (area A: entry pages; B: Admin, Developer,
customization; C: dialogs, pickers, viewer). Their files are listed by area below.

## The foundation (what the next packages get)

### Scope: `ix-lt` (`client/src/styles/ix-longtail.css`, section 1)

Hundreds of call sites in settings, the entry pages and the panels write the Glass names (`text-text-secondary`,
`bg-bg-raised`, `border-border-subtle`, `var(--ink-3)`, `pc-well`). A custom property is substituted where it is
declared, so a Tailwind utility inside a surface reads the Index value only when the surface re-declares the name
and the `--color-*` that points at it. One block does both:

| Class | Surface | Ground (`--bg-base`, focus-ring gap) |
|---|---|---|
| `.ix-lt` | settings, entry pages, anything on the window ground | `--ix-ground` |
| `.ix-lt--main` | a page in main (Admin, Developer) | `--ix-main` |
| `.ix-lt--card` and every `.pc-dialog` | dialogs | `--ix-card` |
| `.ix-lt--pop` and every `.pc-floating` | menus, popovers, pickers | `--ix-pop-solid` |

The scope remaps the ink ramp, the action (cream) and the danger, the fills (`--bg-raised` is the control fill,
`--bg-well` the field fill, `--bg-mod-*` the quiet steps), edges (`--border-subtle` is `--ix-line`), depth (no
resting shadow) and shape (controls 11, rows 12, cards 18 to 20). The Glass type roles keep their names where other
packages still carry them and read Index inside the scope: `glass-kicker` is sentence case 12.5/600,
`glass-title-*` are 17/700, `glass-instrument` is tabular numerals, no narrow cut. In this package's own files
`glass-kicker` became `ix-label` and `glass-instrument` became `tabular-nums`.

Other Index scopes (IX-9's `.ix-sheet`, IX-10's `.ix-sp`) are unchanged and still work; a new surface should use
`ix-lt*` rather than a fourth copy.

### Primitives (`components/ui`, `styles/primitives.css`, `styles/components.css`)

The primitives use Index tokens directly (`--ix-fill-ctl`, `--ix-ink-2`, ...), so they are right on any surface;
the scope is only for the Glass-named utilities a section writes itself.

- `Button`: primary is the cream action (36 tall, radius 11, 14/700; 32 at radius 10 for `sm`; 44 for `lg`),
  `ghost` is a text decision, `glass` is the quiet control fill, `danger` is the danger ink on `--ix-danger-fill`.
  Legacy variant names still build. `IconButton`: 36 tile radius 11, a circle only for the call's 46px control.
- `Input`/`Textarea`/`Select`/`TextField`/`SearchWell`: the `pc-field` recipe (field fill, hairline, 44 tall radius
  12). Focus and the ring are in `ix-longtail.css` (a ring never lives in a recipe a utility can override:
  `cascade.test.ts`); an invalid field keeps the danger edge.
- `Tabs` (segmented): the IX-14 `ix-seg` look (tile radius 12, 32px segments radius 9, lit fill), still one sliding
  indicator. `Switch`: off is the control fill, on is cream. `ChoiceCards`: the chosen card wears `ix-hue-selected`.
  `NavRow`: 34 tall radius 10, the selected row wears `ix-hue-selected` in the place's hue. `SectionLabel`: 12.5/600
  sentence case. `Chip`, `Kbd`, `Divider`, `Plate` (the card), `Well` (the field), `Skeleton` (flat and still: no
  pulse), `EmptyState`, `ErrorBanner`.
- Focus (`ix-longtail.css` section 2): every `.pc-focusable` and the shared control classes draw `--ix-focus`
  (2px outline, offset 2; 3px white in High contrast) instead of focus.css's box-shadow ring.
- Motion (primitives.css): `pc-pop-in` is scale(.97) 180ms (out 120ms); new `pc-dialog-enter` (220ms on the
  spring, out 150ms), `pc-scrim-in/out` (200ms), `pc-toast-in/out` (300ms on the spring from 8px above, out 150ms).
  All transform and opacity. Reduced motion is the global switch (`utilities.css`), which snaps.

Tokens added to the Index block of `tokens.css`: `--ix-scrim` (.5; .8 in High contrast, declared once in each of
the two blocks), `--ix-viewer`.

### Media viewer (§6.10): `ImageLightbox`

## Decisions and deviations

1. **A new stylesheet, `styles/ix-longtail.css`**, imported in `globals.css` before `ix-phone.css` (one line; the
   plan's file list has none for this package). Unlayered on purpose: it must beat the utilities AppShell writes on the
   settings overlay and focus.css's layer. `styles/indexTokens.test.ts` lists it in its import-order check.
2. **Companion e2e specs.** Four workers cannot share one spec file safely, so besides `e2e/index-longtail.spec.ts`
   (settings, dialogs and confirms, toasts, menus and tooltips, sizes and themes) there are
   `index-longtail-auth.spec.ts`, `index-longtail-pages.spec.ts` and `index-longtail-dialogs.spec.ts`. Run each with
   `PARACORD_E2E_INDEX_SPEC=<name>`.
3. **Settings overlay is full-window** (spec §6.7), not AppShell's windowed dialog; done by CSS only.
4. **Tooltip default delay 400ms** applies to every `ui/Tooltip` (it was 0). IX-6's dock tooltip is its own.
5. **Skeletons are still** (no pulse), consistent with §1.2 and IX-10.
6. **`--ix-scrim` appears twice in `tokens.css` on purpose**: the default value in the Index block and the High
   contrast override (.8) in the `[data-theme='glass-contrast']` block. Never twice in one block.
7. Out-of-scope edits, each minimal: `stores/toastStore.ts` (+ test) default 4000ms; `styles/tokens.css` (`--ix-scrim`,
   `--ix-viewer`); `styles/globals.css` (the import); `styles/indexTokens.test.ts` (the new file in `ORDER`);
   `components/message/{GifPicker,StickerPicker}.tsx` (insides).
