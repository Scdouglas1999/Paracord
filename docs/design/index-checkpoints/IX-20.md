## What changed in live code

- `components/ix/card/RoomCard.tsx`, `components/ix/sidebar/ServerSidebar.tsx`:
  Together's "Watching ..." / "Listening to ..." line under the card head for a
  room you are not in (`useGuildTogether` is mounted by the server sidebar).
- `styles/ix-card.css`: the card's wide control has 8px side padding (Back to
  chat reads in full); the waveform's CSS loop steps on one 200ms grid; the real
  waveform's bars step with the level (no transition).
- `gateway/dispatch.ts`: the member count follows `GUILD_MEMBER_ADD` /
  `GUILD_MEMBER_REMOVE`.
- `lib/motion/voiceLevel.ts`: the voice-level loop ticks on the 100ms grid
  instead of every animation frame (`VOICE_GRID_MS`).
- `lib/media/tauriMediaEngine.ts`: `connect` registers its key, roster, track
  and transport listeners before `start_voice_session`.
- `client/src-tauri/src/native_media/events.rs`: speakers are reported by user
  id with the raw -dBov level, every tick while anyone talks;
  `native_media/commands.rs`: one boolean rewritten for clippy 1.91.
- Tests: `CardSlot.test.tsx`, `dispatch.test.ts`,
  `tauriMediaEngine.lifecycle.test.ts` (one new case each, one case made to wait),
  `menus.test.tsx` (waits for focus), `events.rs` (one unit test),
  `index-card.spec.ts` (labels whole at 1280 and 900, a Back to chat crop),
  `crates/paracord-ws/tests/gateway_integration.rs` (clippy).
- Scene drivers (`client/scripts/index-scene/`, `scene-lib/`): Glass paths
  removed, tokens renewed on 401, no healing on a failed read, `setMic` holds.

## For whoever runs the desktop next

- Joining a call from a test desktop is safe with a private PipeWire graph: the
  release check's "How it was driven" says how (a `pipewire -c` config with only
  null nodes, a WirePlumber without device monitors, `.asoundrc` and
  `PIPEWIRE_REMOTE` pointing at it, `PULSE_SERVER` at nothing), and how to prove
  it with `pw-dump` on both graphs before and during the join.
- The approved-origins file (`<data>/com.paracord.desktop/security/approved_origins.json`)
  must list the test instance, or the native trust prompt blocks the connect page.
- `index-scene.mjs` holders now survive token expiry. The cast pages go idle
  after about 10 minutes, so "here now" counts drop in long runs.
