### How it was done without touching anyone's work

Other packages had staged and unstaged changes in this worktree (deletions staged by IX-9, files by IX-5/6/10/14).
`git merge` refuses to run while the index differs from HEAD, and a merge commit would have swept their staged
changes in. So the merge was built with plumbing and nothing of theirs was stashed, reset or touched:

1. `git merge-tree --write-tree HEAD feat/native-video`: one conflict, `client/src/pages/AppShell.test.tsx`.
2. Resolved in a temporary index (`GIT_INDEX_FILE`): HEAD's side. IX-4 rewrote that file for the Index frame;
   native-video's change was to a Glass-frame case ("hides the conversation in theater only…") that IX-4 had
   already removed with the Glass frame tests. Nothing of native-video's intent is lost (theater opening with the
   chat hidden is Glass behavior; the Index call view has its own chat column, IX-13).
3. The resolved tree was checked in a scratch export before anything moved: `tsc` (only error: IX-6's committed
   `Dock.tsx` importing IX-9's then-uncommitted menu exports, not the merge), `vitest run` **427 files, 4542 tests,
   all pass** (the two pre-existing failures, `useGlassKeybinds` and `stageTransition`, pass after the merge:
   native-video fixed their theater-chat expectations), and
   `cargo check --manifest-path client/src-tauri/Cargo.toml --all-targets` with `vpx` on
   (`CARGO_TARGET_DIR=…/Paracord-glass/target`): clean.
4. `git commit-tree` with both parents, `git update-ref` (compare-and-swap on the old HEAD), then only the 49
   merged paths were brought into the worktree and index (`git checkout <merge> -- paths`, `git rm --cached` for
   the five deleted files). None of the 49 overlapped another package's dirty file (checked before and after).

## Reconciliation (what M2 owns, done in IX-13)

Native-video changed `Stage`, `stageTransition`, `StreamSurface`, `nativeUnderlay`, `PillPreview`,
`useStageGlow`, `layout.css` and `glass-stage-modes.css`. Into the Index call view (IX-13, `components/ix/call/`):

- **Moves**: `callMotion.ts` `beginCallMove()` is the Index form of `stageTransition`'s native guard: a
  `data-native-shield` over the window (tiles read it as an occluder and show their posters, still decoding)
  plus `beginNativeMove()` (opaque ground), held for every open, theater and close move, and for 250ms around a
  chat column change. The call surface keeps its own fill while `html[data-native-moving]` is set, and nothing
  beneath it (main, and the sidebar in theater) is painted while a hole is open (`ix-call.css`, end), so no
  video shows mispositioned and no page shows through a live hole.
- **Posters**: native-video moved the poster into each tile's own canvas (`NativeVideoTile.drawPoster`,
  `canvas[data-poster]`), so `useStreamPoster` is gone; the Index tiles and the composed `StreamSurface` get it
  for free. The close copy (`ghostOf`) copies each canvas's poster into the copy.
- **Camera tiles**: `CallTile` ports `CameraTile`'s route exactly (`fit: 'cover'`, `CAMERA_ANCHOR`,
  `useNativeUnderlay`, boundary and clear attributes, canvas hidden while the hole is live).
- `StreamSurface`, `useNativeUnderlay`, `ClipToast`, `SurfacingMessages`, `StageChannelPanel`, `StreamSound`,
  `useStageWatch`, `useStageData`/`stageModel` are composed unchanged.
- `PillPreview`, `RoomBackdrop`, `lib/room`, `useStageGlow`: nothing in the Index UI mounts them (the room card
  replaced the pill, room light is retired), so their native-video changes simply ride along until deletion.
