# IX-12 checkpoint: Message box

Contract: `docs/index-spec.md` §3.1 (message box row), §4.12, §5.12, §5.13, §6.11,
§8.4 (scheduled send, MarkdownToolbar). Plan row: `docs/design/index-plan.md` §3
(IX-12). The send flight (M1) is untouched in behavior; its one token hook was
re-pointed on purpose (below).

## What was built

`MessageInput` is the Index message box. Same draft, same send path, same
permissions; new presentation and the tools the spec names.

```
div.ix-composer[data-testid=ix-composer][data-ix-composer-open=true|false][data-icon-tools?][data-read-only?]  --ix-hue
  .ix-composer__stack            notices, poll card, Send later card, recovery, queue, errors (at the box's width)
  .ix-composer__box.glass-composer__capsule[data-open]     (composerShellRef: pressComposer)
    .ix-composer__shape          .ix-composer__fill (3 solid slices in one .055 opacity group)
                                 .ix-composer__edges (3 slices: quiet edge ::before, open edge + halo ::after)
    .ix-composer__head           attachments queue (52px thumbs, 3 rows max) + row: textarea, emoji, send
    .ix-composer__tools-clip > -move > .ix-composer__tools
                                 [Replying to Jeremy x] Attach GIF Poll Event Format ... Slow mode: 12s  1950/2000
    .ix-complete                 @ / # / : completion and slash commands (SlashCommandPopup), above the box
    .ix-picker                   ComposerPickerHost: Emoji / GIF / Stickers, 360x420, above the emoji button
  IxMenu "Send options"          right-click or 500ms long press on Send: Send later..., Scheduled messages
  EventFormModal                 the Event chip (server only, Manage Server or admin: the Events page's rule)
  ScheduledMessagesPanel         now a SheetFrame sheet (kind "scheduled") in #ix-sheet-host
```

- **Geometry** (pixel-checked against `ref/s0-message-box-open.png`): 52 closed,
  98 open, x 352 to 1244 at 1280 (`margin 0 36 18`: the column padding less 12),
  radius 24, fill `--ix-fill-field`, edge `--ix-line`, open edge .18 and the hue
  halo; row padding 0 8 0 18, 15/22 text; send 36 circle; chips 27px tall at
  y+52, padding 6 10, gap 6. Sampled pixels match the reference to within one
  level (fill 27,28,30; open edge 68,68,70; halo 42,25,30 at Fuel's 350).
- **Open state** (`data-ix-composer-open`): focus anywhere in the box, or words,
  attachments, a reply, the format bar, the picker, a poll or a Send later card.
  Empty and unfocused closes it.
- **Three-slice open, §5.12** (`composerShape.ts`, `useComposerShape`): the
  layout height changes once; a ResizeObserver on the box's border box (it
  fires after layout, before paint) plays the change back: top caps and the
  head `translateY(old-new) -> none`, middles `scaleY(old/new) -> none` from
  their bottom, 500ms spring growing, 350ms shrinking; closing also pushes the
  tools row down through the box's foot (its clip). Every height change uses it
  (open, close, a new line, attachments), except the one the send makes
  (`holdShapeRef`, snaps: M1 rule 6). A change mid-move starts from where the
  shape is drawn. Ids `ix-composer:shape:{top,mid,head,tools}`, never filled
  forwards. Tools row: CSS transition, opacity 300ms after 80ms, translate 6px
  450ms spring (open); 150ms fade (close). Ring: opacity 250ms. Reduced motion:
  snaps, tools fade 150ms.
- **No seams while moving**: translucent slices beside each other showed a 1px
  antialiasing seam (a darker or lighter line, about 4 levels) at fractional
  positions. The fill is now solid slices overlapping by a pixel inside one
  group whose opacity is .055, so the group is what is translucent. Checked at
  2.5x brightness on the filmed frames: no seam.
- **Send (§5.13)**: `--ix-fill-btn` with ink-3 glyph, cream (`--ix-cream`,
  `--ix-cream-ink`) once there is something to send (`data-ready`), 200ms color
  transition. Accessible name stays "Send message".
- **Tools**: each only when permitted. Attach (attach allowed and send
  allowed), GIF (send allowed), Poll (poll allowed; hidden in an encrypted DM),
  Event (in a server, admin or Manage Server), Format (always; swaps the row for
  the formatting bar with a Done chip). In a box under 420px, `narrow`, or a
  phone, chips keep only their glyphs (named by `aria-label` and `title`); GIF
  keeps its word.
- **Emoji button and the one picker (§6.11)**: `ComposerPickerHost` wraps the
  existing `EmojiPicker` / `GifPicker` / `StickerPicker` (not edited) in one
  surface with a tablist (Stickers only in a server), and `ix-composer.css`
  strips their own floating chrome while inside. Arrow keys move tabs; Escape or
  a choice closes and gives the words their focus back.
- **Completion**: @ people and roles (as before), # linkable channels (text,
  announcement, forum), : emoji (the server's own via `emojiApi.listGuild`,
  cached per session, then 120 common shortcodes in `composerCompletion.ts`; a
  load failure is said in the list). Near-solid popover, radius 16, six 40px
  rows then it scrolls; `listbox`/`option` with `aria-activedescendant` on the
  textarea. The caret lands after the token on the same commit (a layout
  effect), so a fast next keystroke cannot land before it.
- **Reply chip** leads the tools row ("Replying to Jeremy x"; just the name in
  a narrow box). Keeps `.glass-composer__reply` and `role=group` "Replying to X"
  (glass-send.spec reads them).
- **Attachments**: 52px image thumbnails and file tiles (extension, name, size;
  "Over 50 MB" and a danger edge when too large) inside the box above the words,
  three rows then it scrolls; remove buttons named "Remove <file>".
- **Send later**: right-click Send, Shift+F10/menu key on it, or a 500ms touch
  press (the press does not send). "Send later..." opens the Send later card
  (the existing schedule composer: Send at, then Send becomes "Schedule
  message"); "Scheduled messages" opens the sheet. The card links to the sheet
  too.
- **Read-only**: when the server's own send decision is a refusal (not loading,
  not an encryption step, not a group waiting on someone's keys, not a probe
  error), the box is replaced by one centered ink-3 line: "Only moderators can
  post in announcements" for an announcement channel and the permission refusal,
  "You can't send messages in clips" for other channels, and the server's own
  words for any other refusal (a block, a timeout, a locked thread).
- **Slow mode**: "Slow mode: 12s" (or 5m, 2h) at the tools row's end from
  `channel.rate_limit_per_user`; the count of characters near the limit sits
  beside it.
- **RoleMentionChip**: ink at 600 (spec: other mentions), hover fill; its card
  uses the Index `Avatar` with the presence dot.
- **Drop files from elsewhere**: `stageComposerFiles(channelId, files)`
  (`components/message/composerFiles.ts`) queues files into that conversation's
  box through the same checks; returns false when no box is open for it.

## The send flight (M1): what changed and what did not

- Kept: `beginSay` before any await and only for plain text; `data-composer-input`
  on the textarea; `composerShellRef` on the capsule (`pressComposer`);
  `sendButtonRef` on the send button; words hidden by opacity on the keystroke;
  `say:settled` in `finally`; no other motion at send (the shape snaps the
  send's own height change).
- The textarea's `padding-left` is 0 and the row's 18px padding puts the first
  glyph at x+18: `readSendOrigin` reads 0 and the box at the glyph, so the words
  leave from where they were typed. Its `color` is `--ix-ink`.
- **Re-pointed on purpose**: `releaseSend` (lib/motion/sendFlight.ts) read
  `--glass-fill-quiet` and `--ink-1` from the button, which the Index button does
  not declare: it would have silently stopped releasing. It now reads
  `--ix-send-quiet` and `--ix-send-quiet-ink`, which `.ix-composer__send`
  declares (its quiet fill and glyph ink). Unit test updated, plus one that a
  control declaring only the old Glass tokens is left alone.
- Verified: `index-send.spec.ts` (WP ix12, frames in
  `output/design-reference/index-build/ix12/send/`) and `glass-send.config.ts`
  (on ports 4607/4609) — results below.

## Decisions and deviations

1. Format is a chip after Event (spec); the prototype has no Format chip and no
   emoji button, so the reference differs by those two only.
2. The "+" menu is gone: everything it held is a chip, the emoji button, or the
   Send menu.
3. The read-only line matches the server's permission refusal text
   (`PERMISSION_REFUSAL`, from `routes/channels/capabilities.rs`) to choose its
   own words; any other refusal is shown in the server's words.
4. Two tokens added to the Index block in `styles/tokens.css`:
   `--ix-edge-open-over` (.11 white: over the .08 quiet edge it makes the .18
   open edge, so the ring fades by opacity alone) and `--ix-fill-field-solid`
   (the field drawn solid inside the .055 group).
5. The drop target over main is IX-15's; the box keeps its own drop handling
   (drop on the box), with the open ring as its drag-over state.
6. Out-of-scope edits, each minimal: `components/guild/EventList.tsx` (`export`
   on `EventFormModal`), `lib/motion/sendFlight.ts` + its test (`releaseSend`
   tokens, as M1 asked), `styles/tokens.css` (two tokens), a narrow-host padding
   rule for `.ix-composer--narrow` (the call chat column and a narrow thread
   relied on the old `glass-composer--narrow` padding).
7. `variant="ribbon"` has no caller left; it is kept as a narrow box.
