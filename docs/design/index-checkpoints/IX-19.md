### The real-server specs, ported

The server and relay assertions are unchanged; only how the UI is driven and read changed.

- **Smoke.** "Your face" is the toolbar's `Your account` button. The edit test right-clicks a message and picks
  `Edit`, types in `Edit your message`, and reads the history through the `edited` mark. "Home follows live
  mentions" is now **the Inbox follows live mention creation, edits and deletion**: People › Inbox rows, the
  count badge (1, then 2, then 1 after the delete), the dock's `Attention verification, 1 mention`, the row
  opening the room at `?message=<id>`, then the empty page ("Nothing is waiting for you"). The welcome-count
  test reads the sidebar header's "2 members" (the Glass welcome overlay no longer exists).
- **Restore.** The member's launch with no memory opens their first server, so the spec clicks the dock's
  People and then the Inbox row (a client-side navigation, no reload, so the observed wire stays the same one),
  and follows the mention count and preview through the cutover.
- **Voice join (4 tests).** The pill is the sidebar room card: join from the card or the empty room row,
  `ix-room-card[data-state="yours"]`, `ix-card-mic`, `ix-card-open-call`, the card's "People here" list for the
  roster. "Microphone on when you join" is Settings › Voice & video › Join calls muted (on by default), set
  through the real UI. Rooms are matched by exact name because a new server already has a default "Lounge".
- **Voice check (3 tests).** Opened from Settings on desktop (and via the sidebar on a phone), and from the
  call view's `More call actions` menu. Leaving closes the call view, so that assertion became "no call view,
  no card, the row is back".

Live voice runs used Chromium's fake devices with `PULSE_SINK=glass_g23_out`; the owner's real devices and the
owner's server (UDP 8443) were not touched (`PARACORD_E2E_MEDIA_PORT` moves the test server off 8443).

## Changed in live code (outside pure deletion)

1. `components/ix/people/peopleModel.ts`: an Inbox or sidebar line reads a mention of **you** as `@you`
   (a mention of somebody the client does not know stays `@someone`). The Glass Home said `@you`; Index's
   "no names" line said `@someone` for your own mention. One unit test.
2. `styles/ix-sidebar.css`: `.ix-search kbd` got `flex: 0 0 auto; white-space: nowrap`. With a long server name
   the "Ctrl K" hint wrapped onto two lines. This is IX-5's file; the change is two properties.
3. `e2e/fixtures/index/drivers.ts` (`walkStates`): after the message box is emptied it waits 1.5 s before the
   reload. The draft is saved a beat after it changes, so an immediate reload brought "testing the box" back
   into the busy state's shots (the folded-title shot went from 3.2% to 2.3% mean difference).
4. `smoke.spec.ts` / the quick-switcher test waits for the first result to be the selected one before Enter. It
   failed once in one full default-config run before this (the URL stayed on the text channel) and not in 12
   repeats alone or in a second full run.

  panel's per-room "Watching ..." line. Index's sidebar and room card do not draw it, so the hook is kept and
  unreferenced. Wire it into the card or delete it.
- **"Back to chat" ellipsizes in the room card at 1280px** ("Back to ch...", IX-13 noticed it; it fits at 900).
  Not touched: `.ix-ctl--wide` is IX-7's and the fix is a spec decision (font size or the control row's gap).
- **`@someone` for people the client does not know** remains in sidebar and Inbox lines (the lines carry no
  member names by design); only your own mention is named.
- **`index-scene`'s `ui.mjs` still holds Glass control paths** that never run on Index (the live scene uses its
  own steps). They are dead, not removed; `index-scene.mjs --check` reports "scene data: consistent".
- **Engines still parse `viewKind 'watch' | 'ambient'`** and the server keeps its dormant ambient view kind. It
  is protocol-level; the client no longer opens an ambient view.
- **`components/glass/*` directory names stay** for the live code listed in `index-summary.md`.
- **`lib/attention`'s light model** (`personLight`, `buildingLight`, `lightCaptions`) still feeds the server
  home page, Friends and the people sheet; the parts nothing called were removed.
- **Legacy classes in `layout.css`, `components.css`, `primitives.css`** (`icon-btn`, `context-menu-item`,
  `command-icon-btn`, `pc-focusable-composed`) are pinned by `cascade.test.ts` and `focus.css`, and left.
- **Sports pin rules.** `.pc-sports-pin-label|-score|-more|-chip|-chevron` in `sports.css` may be overridden by
  IX-10's rules (its checkpoint says so); not verified, not removed.
- **Pre-existing dead non-Glass code** found while walking the graph and left alone: `dmE2ee`, `signalPrekeys`,
  `useScopedAvatar`, `stores/voice/selectors`.
